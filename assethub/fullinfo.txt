1. Create the project

Create a Laravel app with the React starter kit:
01-create-project.sh

laravel new media-vault
cd media-vault

When prompted:

    Choose a React starter kit.
    Choose Laravel’s built-in authentication.
    Choose MySQL/MariaDB if asked.
    Do not start a local development server yet.

Install the two extra packages:
02-install-packages.sh

composer require php-amqplib/php-amqplib
composer require league/flysystem-aws-s3-v3

npm install

Laravel’s S3 filesystem driver works with S3-compatible storage such as MinIO when configured with the MinIO endpoint and credentials. (laravel.com)

3. Environment template

Replace .env.example with this:
.env.examplev3

APP_NAME="Media Vault"
APP_ENV=local
APP_KEY=

Redis is used only for shared session and cache data. MariaDB is the durable source of truth for users and file metadata; MinIO is the durable location for actual uploaded file bytes.

7. Publish a RabbitMQ message

Create the publisher service:
app/Services/RabbitPublisher.phpv4

<?php

namespace App\Services;

use PhpAmqpLib\Connection\AMQPStreamConnection;

The message contains only an ID, for example:
file-uploaded-message.json

{
  "file_id": 12
}

It does not include the actual document, image, or video. That file stays in MinIO.

12. Build one container image

This intentionally runs Nginx and PHP-FPM in one container via Supervisor. In a larger production system, you might separate them into containers, but one application container is simpler for this first Kubernetes learning project.

Create this Nginx configuration:
infra/nginx/default.confv4

server {
    listen 8080;
    server_name _;

    root /var/www/html/public;
    index index.php;

Create Supervisor configuration:
infra/supervisord.confv2

[supervisord]
nodaemon=true

[program:php-fpm]
command=php-fpm
autostart=true

Create the Dockerfile:
Dockerfilev4

FROM node:22-alpine AS frontend

WORKDIR /app

COPY package*.json ./
RUN npm ci

Create .dockerignore:
.dockerignorev2

.git
.env
node_modules
vendor
storage/logs
storage/framework/cache

13. Kubernetes: one complete manifest

Create one file containing the local Minikube setup:
infra/k8s/all.yaml

apiVersion: v1
kind: Namespace
metadata:
  name: media
---
apiVersion: v1

The Ingress sends browser HTTP traffic to the media-web Service. Kubernetes requires an Ingress controller for an Ingress resource to have an effect; Minikube’s ingress add-on provides that controller. (kubernetes.io)
14. Start Minikube and deploy

Start Minikube and enable its Ingress controller:
03-start-minikube.sh

minikube start --cpus=6 --memory=8192
minikube addons enable ingress

Build the application image inside Minikube:
04-build-image.sh

minikube image build -t media-vault:dev .

minikube image build builds an image using Minikube’s container runtime, so this workflow does not require you to run Docker CLI commands directly. (minikube.sigs.k8s.io)

Create the namespace and then create your local-only Secret:
05-create-secret.sh

kubectl apply -f infra/k8s/all.yaml --dry-run=client -o yaml >/dev/null

kubectl create namespace media --dry-run=client -o yaml | kubectl apply -f -

php artisan key:generate --show

Copy the output of php artisan key:generate --show, then use it here:
06-create-kubernetes-secret.sh

kubectl -n media create secret generic media-secrets \
  --from-literal=APP_KEY='base64:PASTE_THE_GENERATED_KEY_HERE' \
  --from-literal=DB_PASSWORD='local-db-password' \
  --from-literal=MARIADB_ROOT_PASSWORD='local-root-password' \
  --from-literal=AWS_ACCESS_KEY_ID='minioadmin' \
  --from-literal=AWS_SECRET_ACCESS_KEY='local-minio-password' \

Apply everything:
07-deploy-everything.sh

kubectl apply -f infra/k8s/all.yaml

kubectl -n media get pods --watch

Wait until MariaDB is running, then run the Laravel migrations:
08-run-migrations.sh

kubectl -n media exec deployment/media-web -- \
  php artisan migrate --force

Wait for the bucket creation Job:
09-wait-for-bucket.sh

kubectl -n media wait \
  --for=condition=complete \
  job/minio-create-bucket \
  --timeout=180s

    Go to /files.
    Upload any file smaller than 50 MiB.
    The page initially shows:

    Click Download.
    In MinIO, confirm the actual file is in:

    Scale Laravel web pods and confirm your login remains valid:

11-scale-web-pods.sh

kubectl -n media scale deployment/media-web --replicas=3

If that works, you have learned the core point of the project:

    shared database: MariaDB;
    shared session/cache: Redis;
    shared file storage: MinIO;
    shared background queue: RabbitMQ;
    independent web and worker pods: Kubernetes Deployments;
    browser entry point: Nginx and Ingress.
